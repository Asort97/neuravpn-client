# Discord Jalapeno Cleaner

Бот удаляет уже опубликованные и новые сообщения конкретного внешнего Discord-приложения.

## 1. Создать бота

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, задайте любое имя.
3. Откройте **Bot** → **Reset Token** → скопируйте токен.
4. Не публикуйте токен и не отправляйте его другим людям.

Привилегированный `Message Content Intent` этому боту не требуется.

## 2. Настроить

В папке бота выполните:

```powershell
Copy-Item .env.example .env
notepad .env
```

Минимально заполните:

```dotenv
DISCORD_TOKEN=ваш_токен
GUILD_ID=ID_вашего_сервера
TARGET_APP_NAME=Jalapeno
```

Для безопасной точной фильтрации заполните `TARGET_APP_ID`:

1. Discord → **Настройки пользователя → Расширенные → Режим разработчика**.
2. Нажмите ПКМ по имени/аватару сообщения Jalapeno.
3. Выберите **Копировать ID пользователя** или **Копировать ID приложения**.
4. Вставьте число в `TARGET_APP_ID`.

Если скопировать ID не получается, оставьте поле пустым: бот будет удалять только сообщения
ботов/приложений с точным именем `Jalapeno`.

## 3. Пригласить

В Developer Portal:

1. Откройте **OAuth2 → URL Generator**.
2. Выберите scope **bot**.
3. Выберите права:
   - **View Channels**;
   - **Read Message History**;
   - **Manage Messages**.
4. Откройте созданную ссылку и добавьте бота на сервер.

Готовая сумма разрешений — `74752`. Можно использовать ссылку такого вида, заменив
`APPLICATION_ID`:

```text
https://discord.com/oauth2/authorize?client_id=APPLICATION_ID&scope=bot&permissions=74752
```

Убедитесь, что права бота не запрещены отдельными настройками нужных каналов.

## 4. Запустить

```powershell
npm install
npm start
```

При запуске бот очищает всю доступную историю, затем остаётся включённым и сразу удаляет
новые сообщения Jalapeno. Остановка: `Ctrl+C`.

Дополнительно отключите у `@everyone` разрешение **Use External Apps**: тогда приложение
вообще не сможет публиковать новые публичные ответы.
